# 质量门禁

## Research gate

- 考试类别、年度、地区、科目和专业口径明确。
- 每条关键结论至少一个直接来源，来源覆盖率 100%。
- 无未处理的废止条款、来源冲突或高风险不确定性。
- 教材/讲义/题库的权利和第三方处理状态已记录。

## Content gate

- 分镜 5–9 段，ID 连续，每段有旁白、屏幕信息和 `claim_ids`。
- 数字、单位、公式、规范号和适用条件与证据一致。
- 计算内容可复算；安全、质量和施工要求均标为高风险。
- 横竖版使用相同结论和旁白，不出现内容漂移。

## Render gate

- HyperFrames `check` 的 lint、runtime、layout、motion 和 contrast 无未处理 error；警告逐条确认。
- 输出分别为 1080×1920 与 1920×1080，具有有效 H.264 视频轨和 AAC/兼容音频轨。
- 字幕与配音同步，无截断、乱码、遮挡、低对比和空场景。
- 技术箭头、标号、步骤、图例和单位正确；生成图不承载技术结论。
- 蒙太奇逐场景目视复核。

## Human approval gate

`review/review.json` 至少包含：

```json
{
  "status": "approved",
  "reviewer": "审核人姓名",
  "role": "专业审核人",
  "reviewed_at": "ISO-8601 时间",
  "version": "脚本和成片版本",
  "notes": "审核意见"
}
```

状态为 `pending` 或 `rejected` 时只能交付审阅版。任何来源、关键数字、旁白或技术图示变更都会使原批准失效，必须重新审核。
