# 来源、版权与资料安全

## 来源优先级

1. 国家法律法规数据库、国务院及正式法规发布渠道。
2. 住房和城乡建设部、人社部及其他主管部门。
3. 中国人事考试网、省级考试机构和正式考试通知。
4. 可确认现行状态的工程建设标准、考试大纲和标准条文。
5. 有合法使用权的教材、讲义、题库和内部制度。
6. 高校、行业协会和专业机构解释材料。
7. 普通媒体、自媒体和论坛只作线索，不单独支持高风险结论。

## 证据规则

- 把结论拆成可独立验证的原子 `claim`，不要用一个来源笼统支撑整段脚本。
- 高风险结论必须有直接来源，并核对版本、发布日期、施行日期、地区和适用条件。
- 规范号、条款号、数字、单位和原文引用逐字核对。
- 来源冲突时记录效力层级和差异，无法解决则停止正式版。
- 普通网页记录标题、机构、URL、发布日期、访问日期和支持的 `claim_ids`；资料记录文件名、页码和版本。

## 版权规则

- 每批资料在 `inputs/rights.json` 记录：所有者、授权状态、内部研究、第三方处理、公开引用、公开复图权限。
- 允许把教材、讲义和题库上传已批准第三方服务做内部研究，但只上传当前步骤所需片段。
- 不复制整页、大段正文、完整题库、付费讲义结构或原始版式。
- 公布内容优先使用事实结论、原创转述和原创图解。
- 必要直接引用保留作者/机构、作品名、页码/章节和引用目的；公开发布前人工确认范围。
- “教学用途”不自动等于可以公开传播。权利不明时只作内部事实线索，不呈现原文或原图。

## 敏感资料

- 内部资料可使用第三方 AI，但仍须最小化上传、日志脱敏和权限核对。
- 明确禁止外传、包含个人信息、未公开项目数据或受限图纸时只在本地处理。
- API Key 只从环境变量读取；不得进入项目、截图、日志、报告或提交记录。
