# 动态图形计算用例库

优先选择“图形变化能解释计算关系”的题型。用例数据应原创，考试范围由现行官方大纲确认；教材、讲义和题库只用于内部研究，不复刻题干和图。

|---|---|---|---|---|
| P0 | 一建/二建项目管理 | 双代号网络计划：前推、后退、总时差、关键线路 | 节点弹入、箭线逐段绘制、时间参数落位、关键线路高亮 | 逻辑关系或时间参数算错；虚工作规则遗漏 |
| P0 | 一造土建计量 | 放坡基坑几何体积：顶底尺寸、三截面、体积 | 剖面开挖、尺寸线绘制、三平面展开、公式代入 | 把演示放坡值误当规范或计量规则 |
| P1 | 一建工程经济 | 现金流量图与净现值 | 时间轴延伸、现金箭头升降、逐年折现、累计值更新 | 时点、正负号、折现期数混淆 |

## 已实现基线

### `network-plan`

输入节点、工作和持续时间后，渲染器按 SVG 用户坐标生成箭线网络。`critical: true` 的工作在普通网络完整出现后统一高亮；不要让模型自行猜关键线路，必须先在计算底稿中复算。

### `earthwork-volume`

输入底长、底宽、深度和几何放坡值后，渲染器生成剖面、三层平面和四步代入。组件只负责确定性绘制和算术展示，不负责判断现行计量、安全或施工方案口径。

### `cashflow`

输入分期现金流和折现率后，渲染器生成时间轴、正负现金箭头、逐期现值和净现值。现金流数据与取位规则必须先写入计算底稿。

### `component-volume`

输入三类构件的名称、计算式和体积后，渲染器生成梁板柱爆炸拆分与分类汇总。基线只表达互不重叠的独立几何体；涉及扣减、并入和界面划分时必须另行绑定现行计量规则。

### `flow-schedule`

输入施工段数、施工过程和流水节拍后，渲染器生成按时间推进的流水横道。基线用于无间歇、无搭接的等节奏演示；条件变化时不得直接套用。

### `rebar-length`

输入分段长度、转向角度和可选总长后，渲染器按比例绘制钢筋路径、弯折标记、分段尺寸和累加条；`total` 与分段和不一致时构建报错。基线只做几何长度累加演示；锚固长度、弯钩增量和保护层取值高度依赖来源，必须逐项绑定证据，不得使用演示默认值。

### `earned-value`

输入期序列与 PV/EV/AC 三序列后，渲染器生成三曲线生长、`focus_period` 期的 CV/SV 差值展开和指标 chips。指标定义、正负号和结论方向必须先在计算底稿复算。

### `projection-point`

输入空间点坐标后，渲染器生成三面投影体系（H/V/W 轴测视图：面、轴、点、投影线、三投影）或展开图（V 不动、H 沿 OX 下转、W 沿 OZ 后转、Y 轴分两条、投影对齐线）。点坐标为演示数据时按原创数据口径声明；投影落点须在计算底稿按定义复算。

## 续演与节拍

- 同一图形多步演示（前推→后退→关键线路等）从第二场起使用 `animation.mode: "continue"`，结构组静态就位，只动画本场新增标注；进入转场自动为 `hold`。
- 动画组默认按顺序铺满整段旁白窗口；需要与某句旁白精确对位时用 `animation.beats`。组名清单见 `content-templates.md`。

## 验收方式

1. 先看场景中点蒙太奇 `preview/montage-<profile>.png`，检查内容、尺寸和画幅安全区。
2. 再看动效进度图 `preview/motion-<profile>.png`（每场 20%/55%/90% 三帧），确认路径、尺寸或构件本身随旁白推进；只有卡片淡入视为不合格。续演场景需确认结构组三帧位置一致、无重放跳动。
3. 对网络图逐项复算最早时间、最迟时间、总时差和总工期；对几何体独立复算尺寸、面积、体积与单位。
4. HyperFrames 的 lint、runtime、layout、motion 无 error 和 warning；转场离场帧的 info 需确认属于有意画布外运动。
